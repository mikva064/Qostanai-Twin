# Zauyt AI

MVP цифрового двойника автомобильного завода для Qostanai Industry Hackathon, кейс АО «Группа компаний АЛЛЮР». Версия 0.12.0; первичный отбор — 9 октября 2026 года.

Проект показывает учебную линию, загрузку и простои постов, качество, события, прогноз выпуска и сравнение вариантов восстановления. Есть история CSV, архив сценариев, данные тестового DOCX и ИИ-агент с инструментами анализа.

## Запуск на Windows

Нужен Python 3.11+. Готовый интерфейс включён в репозиторий: Node.js понадобится только для разработки.

```powershell
git clone https://github.com/mikva064/Zauyt-AI.git
cd Zauyt-AI\qostanai-twin
.\setup.cmd
.\start.cmd
```

При первой установке зависимостей нужен интернет. Откройте [приложение на своём компьютере](http://127.0.0.1:4173/#demo). Остановка сервера — Ctrl+C; состояние сохраняется в локальной SQLite. Также можно скачать репозиторий через Code → Download ZIP и запустить `qostanai-twin/start.cmd` после распаковки.

## ИИ-агент

В папке `qostanai-twin` скопируйте `.env.example` в `.env` и заполните `OPENAI_API_KEY` своим ключом. Перейдите в «ИИ-агент», проверьте подключение и задайте вопрос. По умолчанию используется `gpt-5.4-mini` через [Responses API с вызовами функций](https://developers.openai.com/api/docs/guides/function-calling).

Агент получает тестовые показатели или снимок симулятора, сравнивает варианты восстановления и показывает основания ответа. Он не меняет линию. Ключ хранится на сервере и исключён из Git. Для чата нужны интернет и доступ к OpenAI API; без ключа остальные разделы работают. 6 октября проверен один реальный ответ по качеству окраски; шесть остальных контрольных вопросов ещё ожидают прогона. [Проверка агента](qostanai-twin/docs/AGENT_EVALUATION.md) сверяет эталонные числа и сохраняет ответы для оценки. Автоматические тесты в CI используют подставного провайдера.

## Разработка и проверки

Из папки `qostanai-twin`, Node.js 22.18+ / 24 и Python 3.11+:

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run build
.\.venv\Scripts\python.exe -m unittest discover -s backend -t . -v
```

На Linux используйте `python3 -m venv .venv`, `.venv/bin/python -m pip install -r requirements.txt`, затем `.venv/bin/python -m uvicorn backend.api:app --host 127.0.0.1 --port 4173 --workers 1`. Команды npm выполняются без `.cmd`. Автоматические проверки GitHub Actions собирают интерфейс и запускают тесты без API-ключа.
