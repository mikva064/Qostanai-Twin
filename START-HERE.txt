QOSTANAI TWIN — КОМПЛЕКТ ДЛЯ ПОКАЗА 0.12.0
Первичный отбор: 9 октября 2026 года

1. Распакуйте весь ZIP в отдельную папку на ноутбуке для защиты.
   Не запускайте приложение прямо из окна архива.
2. Установите Python 3.11 или новее, если его ещё нет.
   Python и готовое окружение .venv в комплект не входят.
3. Откройте папку qostanai-twin. Выполните setup.cmd заранее:
   при первой установке нужен интернет для загрузки зависимостей из PyPI.
4. Запустите check.cmd. Он проверяет Python, зависимости, файлы,
   версию сборки и сервер. Сообщение «сервер не запущен» до запуска нормально.
5. Запустите start.cmd и оставьте окно открытым.
6. Откройте http://127.0.0.1:4173/#demo
   В разделе «Показ» нажмите «Проверить готовность».
7. Нажмите «Начать учебный показ» и пройдите шесть шагов.
   Проверка сама не сбрасывает и не переключает линию.
   На новом ноутбуке нет сохранённых импортов: учебный CSV можно
   выбрать и импортировать в разделе «История».

Если уже работает старый сервер: остановите его в прежнем окне через
Ctrl+C и запустите start.cmd из новой папки. Скрипт не закрывает процессы.
Если работает актуальный сервер, start.cmd предложит его использовать.
Рабочая база хранится в data/twin.sqlite3 и сохраняется после перезапуска.
Для переноса своей базы остановите прежний сервер и скопируйте всю data.

Раздел http://127.0.0.1:4173/#case содержит тестовые данные из Word
и объяснимые выводы. Это отдельный исторический срез; модель ИИ не обучена.

Раздел http://127.0.0.1:4173/#agent — чат ИИ-агента. Для него нужен интернет
и свой ключ OpenAI API: скопируйте qostanai-twin/.env.example в .env
в той же папке, заполните OPENAI_API_KEY и нажмите «Проверить подключение».
Ключ не вводится в чат. Подробности: qostanai-twin/docs/AI_AGENT.md.

В комплекте:
- qostanai-twin: готовый интерфейс, сервер, исходники, тесты, примеры и документы;
- pitch-oct09: презентация v3 для отбора;
- MANIFEST.json: список файлов, размеры и контрольные суммы SHA-256.

Подробности: qostanai-twin/docs/RELEASE.md.
Реплики ведущего: qostanai-twin/docs/PITCH_SCRIPT.md.
Контрольные цифры: qostanai-twin/docs/DEMO_GUIDE.md.

После установки основные разделы работают локально без интернета. Перед защитой
проверьте это на целевом ноутбуке, откройте презентацию, пройдите показ
на проекторе и запишите резервное видео. Эти проверки не заменяются check.cmd.
Node.js для готового интерфейса не нужен; он требуется для пересборки.

Это учебная модель и тестовый набор кейса. Агент использует готовую LLM
с инструментами чтения; обучение прогноза поломок не выполнялось.
